## Overview

Codert is an online coding platform for students to automate grading, built during my first-year industrial practical training (IPT) at the University of Dodoma. It works like Codeforces: instructors create test cases, students submit code, and the platform grades automatically.

The system was initially written in Java Servlet and later rewritten in Spring Boot.

## Key Features

- **Automated grading**: Instructors define test cases; submissions are judged against them automatically.
- **Multiple languages**: Supports C++, JavaScript, Java and Python — the initial languages taught at the university.
- **Real system architecture**: Uses Supabase for the database and Fly.io for the backend server.

## Technologies Used

- **Spring Boot**: Rewritten backend, replacing the legacy Java Servlet implementation.
- **Supabase**: Database and authentication infrastructure.
- **Fly.io**: Backend server hosting.

## Status

Currently experimental and may be offline to avoid hosting costs. Try it live at [codert.netlify.app](https://codert.netlify.app).
